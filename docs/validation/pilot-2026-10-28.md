# Synthetic diagnosis pilot

**28 October 2026 · Groq · `openai/gpt-oss-20b`**

Three synthetic cases were run once each through the diagnostic CLI. All returned
accepted output, exit code 0 and the expected status.

## Results

| Case | Result | Finding | Saved response |
| --- | --- | --- | --- |
| [Clear](../../data/synthetic/checkout.json) | `hypothesis` | Missing `PAYMENT_API_URL`, supported by E2 | [Response](pilot-2026-10-28/clear.json) |
| [Ambiguous](../../data/synthetic/checkout-ambiguous.json) | `insufficient_evidence` | No cause asserted; deployment timing alone was insufficient | [Response](pilot-2026-10-28/ambiguous.json) |
| [Insufficient](../../data/synthetic/checkout-insufficient.json) | `insufficient_evidence` | No cause or observations invented; requested more evidence | [Response](pilot-2026-10-28/insufficient.json) |

## Method

[Expected outcomes](../../evals/pilot-cases.json) were defined before inference
and excluded from model input. No retries, response repairs or prompt changes
were used. All three outputs are preserved unchanged. The records retain hashes,
timings and source context; provider usage and response IDs were unavailable.

## What the review found

- **Clear:** the cause is supported, but missing evidence was left empty despite
  the unknown reason for the configuration omission. The response also suggested
  a restart; no action was executed.
- **Ambiguous:** suggested dependency names were not established by the input.
- **Insufficient:** network/DNS checks were suggestions without supporting observations.

This was an assistant review; independent human review is pending. Three
synthetic runs do not establish accuracy, reliability or production performance.
Valid schemas and citation IDs alone do not prove that an answer is supported.
