# Frontend

The web client for IncidentClue will live here. No frontend framework, package manifest, or application has been added yet.

The client will submit incidents and display investigation status, diagnoses, and supporting evidence through the backend's HTTP API. Model-provider credentials, diagnostic tool execution, and database access belong to the backend.

Choose the frontend framework and define API integration when implementing the interface. Keep dependency and build configuration within this directory. See [architecture](../docs/architecture.md) for the planned application boundaries.
